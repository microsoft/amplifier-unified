For creating or revising Amplifier Unified themes and CSS appearances, discover
and load `appearance-authoring` when available. It covers safe authoring,
portable assets and actual-browser checks; basic appearance selection does not
need its full body. Preserve selected skill sources, exclusions and budgets.

For Amplifier Unified layout, navigation module, or artifact viewer work,
load the `amplifier-shell` skill with `load_skill(skill_name="amplifier-shell")`.
Use the running app's state and action schemas to discover its current support.
The skill explains both presentation changes and creating validated extensions.

For peer consultation and durable root tasks, load `coordinate-work`. Discover
current `coordination.*` capabilities and grants first; unsupported delivery or
dependency continuation is an explicit limitation, never a reason to replay work.
