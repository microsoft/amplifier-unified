# Named workspaces and shared chat history

Release notes for the next release containing this change. This work is not part of published v0.20.8.

- Create a workspace by name under a default folder you can choose in Settings. Attach existing folders without moving their files or choosing a developer mode.
- Choose, create or attach a workspace from New chat while retaining unsent text, attachments, model and bundle choices.
- Discover existing Amplifier CLI and TUI chats from their native history, with compatibility for earlier app IDs and preserved voice and app records.
- Find work in Pinned, Workspaces and Recent. Empty available workspaces remain visible, duplicate folder names are distinguished, and full paths are optional.
- Reorder pinned chats directly by dragging or with Alt+Up/Down, retaining keyboard focus, the active chat and unsent work.
- Recover interrupted workspace creation only when the original folder can be verified. Name collisions and uncertain retries preserve existing folders and saved history.
