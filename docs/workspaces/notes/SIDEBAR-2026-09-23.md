# Sidebar consolidation qualification — 2026-09-23

## Delivered behavior

The sidebar has one Pinned control, one Workspaces explorer and one Recent list.
Each section collapses independently and retains that choice per attached client.
The old simple view and Workspaces/All chats toggle no longer choose different
renderers. Pins keep their full title, workspace subtitle, status, activity time
and actions while the user browses or filters elsewhere.

A single `ReorderList` now owns pin and Settings order mechanics: full-row floating
preview, placeholder, insertion marker, pointer/keyboard movement, scroll assistance,
focus restoration, reduced-motion handling and cancellation. Pins save on drop;
Settings still previews locally and saves only after Save order. Pending actions
block duplicate moves, failed saves restore the authoritative order, and a changed
pin set cancels a held drag. Reordering never selects another conversation.

Workspaces retains the richer recent/folder explorer, full-path search, distinct
parent labels and click-through to workspace chats. Available registered folders
with zero chats remain visible so a newly created workspace can be found. Native
worker sessions are excluded from chat lists. Recent contains unpinned chats
across locations and retains separate filters. Lists show all matches through 50
and pages of 40 above 50. Pins use their own bounded projection; reordering a page
preserves pins outside that page.

The canonical native-history index remains the source of chat membership. There
is no parallel workspace/chat registry, no history migration, and no runtime
mount merely from browsing. Existing shell module identities and shared agent/UI
actions remain available. Saved `navSimple` is accepted but ignored for rendering.
See [navigation contract](../../navigation.md) and
[workspace experience contract](../contracts/experience.v1.md).

## Validation

Rebased on upstream main `8d95f6d7` (release 0.20.10) and rebuilt packaged frontend assets from the
combined source. Source changes did not conflict; generated asset conflicts were
resolved by a fresh Vite build.

Checks on the final sidebar source (the final rebase added only upstream release
metadata and private voice diagnostics; the build, 207-test backend selection and
production navigation browser were rerun after it):

- Frontend unit tests: **305 passed**.
- Targeted backend tests including navigation, projections, workspace creation,
  native-history membership, client state and upstream voice/diagnostics integration:
  **207 passed**.
- Production-asset navigation browser: three saved sections, bounded pages,
  consistent pins, full drag contents, drop/Escape/outside/concurrent-change
  cancellation, keyboard focus, details/rename, client/agent parity, retained
  drafts, reload, and desktop plus 320/390 px light/dark layouts passed.
- Production-asset Settings collections browser: shared drag preview, draft-only
  drop, cancellation, Save, keyboard/position controls, private drafts, catalog
  pagination and narrow layouts passed.
- Production-asset workspace experience browser: **13 scenarios passed**, including
  create/attach/collision/cancel, visible empty folders, configured root, first
  send, attachments, unsent text, pins, reload and narrow layouts.
- Native-history browser: 5,000 indexed summaries, 40-row navigation pages, stable
  history scroll loading, read-only worker history, no automatic runtime mount,
  refresh and draft preservation passed.
- Workspace explorer browser: native discovery, empty registered folders, nested
  browsing, path disambiguation, persisted agent/UI state and attachment passed.
- Conversation-library browser: archive/restore and sidebar archive filters, draft
  preservation, immutable shared snapshots, revocation and mobile layout passed.
  The harness now reflects the already-removed collection UI and current receipts.
- Review browser: persisted unread rollups, completion acknowledgement boundaries,
  saved preview/source/download and narrow layout passed.

Additional checks before the upstream voice/release rebases:

- Backend full suite: **3,609 passed, 131 skipped, 1 warning**. This run began
  before the final empty-folder and activity-count refinements; those refinements
  are covered by the final targeted backend tests above. This is not a full-suite
  qualification of the final combined commit.
- Chat-library browser: native roots, paging/search, durable pins across a real
  service restart, mobile touch and saved custom skin passed.
- Mobile navigation browser and sidebar activity browser passed. Steady synthetic
  progress caused no shell/view refetch requests; stable order and drafts survived.
- Large-library performance browser after the final backend refinements:
  **22,915 sessions, 3,932 workspaces, four browsers, one terminal stream**;
  every draft retained, at most one view request in flight per browser, no model
  calls. Recorded p95 latency: health 116 ms, admission 59 ms, actions 272 ms.
  These synthetic local measurements are regression evidence, not Spark benchmarks.

## Release boundary

This change has no version bump and does not update Spark or the Mac PWA service.
The shipping owner must qualify the final PR commit through the release pipeline
and verify the deployed PWA. Local browser fixtures prove the packaged UI and
shared actions; they do not claim acceptance on the live Spark installation.
