# Working on the current web client

Read [README](README.md) for the current HTTP/SSE boundary, pinned upstream
vision/contracts, build commands and unresolved test ownership. The repository
is private; preserve its visibility. Independent source work remains coordinated
with Unified until its distribution adopts the component.

Author browser behavior in `src/`, standalone pages in `public/`, and client
build/preparation in `scripts/`. `dist/`, `.build-inputs/`, generated public
branding/licenses and dependencies are disposable output. Do not edit them or
load them into routine source review. Change canonical catalogs/SDK/branding
with their Unified owner, then select a fresh exported lock here.

Use the named portable tests and installed-artifact fixture for this boundary.
The remaining imported tests have not all been classified; preserve their
assertions and keep failures visible. Actual server, release and example tests
remain with the linked Unified owners. A fixture pass is not actual-server,
provider, release or cross-version acceptance.

Keep one explicit paired server revision in artifact evidence. Do not add a
compatibility registry, runtime asset override or automatic fallback. Follow
the workspace's owned-DTU rules for builds/browser work and remove obsolete
owned copies when their review purpose ends; preserve useful finite evidence.
