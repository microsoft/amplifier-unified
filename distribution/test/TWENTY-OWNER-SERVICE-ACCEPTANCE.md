## Real Linux manual-systemd handoff (opt-in)

Use the same command with `FULL_OWNER_SERVICE_MODE=manual-systemd` on Linux.
An explicitly enabled test on another OS fails rather than replacing pidfd or
systemd evidence. Default ordinary test discovery skips this opt-in fixture.

Requirements:

- A functioning task user systemd manager and read-only `systemctl --user`
  inspection; Python3 with `os.pidfd_open`, default /usr/bin/python3 or explicit
  SYSTEMD_OBSERVER_PYTHON.
- A unique task-owned temporary root and user-unit name, generated by this test.
  The test writes only that new unit with exclusive creation, Type=simple,
  Restart=no, KillMode=control-group, disabled boot start and no triggers.
- Installed native/catalog/owner interpreters built for Linux. Do not copy a
  macOS venv or change an existing host's runtime to run this fixture.
- The retained native Foundation shared-identity version and managed-family fix
  must be present; the local receipt used Foundation8462030d, native71bdf38 and
  catalog36fe815. Use exact newer qualified artifacts only with separate receipts.

The source wrapper consumes its one-shot launch guard before opening the app or
listeners. It checks exact signed installed bytes, configured20-owner census,
private state bindings and the original Linux invocation. The controller binds a
pidfd before retirement, holds every real owner, waits for the signed closed
receipt and kernel exit, then launches exactly one owned destination with the same
release and saved paths. The old unit is explicitly attempted once and must refuse
relaunch. New destination service-stop must also qualify all20 owners.

No PID adoption, external service signaling, fake idle, mocked observer, history
copy or work replay is allowed. The script stops and removes only its own unique
test unit during cleanup and retains its private data/evidence. An uncertain
fixture remains identified in output; it is not automatically retried.

Linux systemd execution was not performed on the local macOS host. The script is
ready for a separately authorized isolated Linux run; source checks or the owned
POSIX result do not substitute for that platform receipt.
