Install the Terminal app

Use a terminal window on this computer with your conversations and tools running on .

Setup handles the client, saved connection and launcher for you. Internet access is required during installation.

Other computers

Intel Macs, older macOS and native Windows are not supported by this installer yet. Setup checks your computer before making changes.

This terminal will have access to your conversations and actions on this service. You can remove its access below. Work already accepted by the service will continue.

Finish on this computer

  1. Download setup file Save it in Downloads.
  2. Open your preferred terminal app (such as WezTerm, iTerm2 or Terminal), paste this command and press Return. It installs on the computer where you run it.
  3. Wait for “Ready,” then run amplifier-terminal in that same terminal window. It opens your saved connection here, without launching a different terminal app.
    If the command isn’t found

    Run the full saved command:

    "$HOME/.local/share/amplifier-terminal/launch"

    Setup prints the exact command for custom installation locations.

    Optional Mac window launcher

    Double-click the Amplifier Terminal .terminal file in your home Applications folder to open it in Apple Terminal instead. Setup prints its location.

About this setup file

Keep it private until it expires. After setup, you may delete the download. Your existing terminal installations and conversations are preserved.

Registered terminals

These installations have access to this service. Registration does not mean a terminal window is currently open. This list updates automatically while the page is visible.
