Download extension preview
First time? Install the development preview

If your browser shows a certificate warning for this service, finish HTTPS setup before connecting. Dismissing the warning can let approval work while the extension’s background connection fails.

  1. Download and unzip the extension preview.
  2. Open your browser’s Extensions page and enable Developer mode.
  3. Choose Load unpacked and select the amplifier-connect folder.
  4. Return here and choose Open and connect.

This PoC is for Chrome and Edge. Store installation and native-client installers are separate follow-up work.

For tasks across pages, install the latest extension preview, open the extension connection page and choose Enable tasks across pages. Approve that added access once, then choose Use this tab across pages in its toolbar popup. Older connections keep their document-only access.
