# Amplifier Tempo for macOS

The native client, artwork, build workflow, and private preview downloads are now
maintained in [bkrabach/amplifier-temp](https://github.com/bkrabach/amplifier-temp).
Repository access is required. The product name remains **Amplifier Tempo**.

This Unified repository owns the authenticated `/api/companion` observation
endpoint, session command APIs, and browser chat links consumed by Tempo. The
native client does not bundle or install a Unified host.

See [host/browser acceptance](../../docs/testing/macos-companion-preview.md) for
this candidate's validation. Original native sources remain available in commit
`9cdd5e400d923400c422be7a55b5cba0443636a2`; standalone source attribution points to
that exact revision.
