# Preview artwork

Arc (cyan/amber), Relay (blue), and Crest (purple/blue) were generated for this
project from the owner's selected Amplifier Edge + Flow concepts. Arc uses the
rounded triangular swirl from the selected reference. No faces or limbs.

Each transparent PNG is 1536 × 2288: eight columns of 192 × 208 cells,
nine activity rows followed by sixteen clockwise look directions. Activity frame
counts: 6, 8, 8, 4, 5, 8, 6, 6, 6. Look rows have eight frames each, starting
at up (000°), clockwise through right (090°), down (180°), left (270°).

The full selected design inventory remains Accord, Relay, Arc, Crest, Fold,
Chord, and Meter; colors exclude white lights. Only these three approved
preview variants are bundled in this initial client.
